# 🛠️ Skrip Utiliti Pembangunan (Developer Scripts)

Direktori ini menyimpan skrip bantuan pembangunan, penyelenggaraan kod, dan pengujian dalaman bagi projek **Dashboard ADTEC Melaka**.

## 📁 Senarai Skrip

- **`check_users.js`** — Menyemak senarai pengguna dan status pengesahan di dalam pangkalan data Supabase Auth.
- **`test.js`** — Skrip ujian pemaparan halaman menggunakan Puppeteer.
- **`replace.js` / `replace.cjs` / `replace2.js`** — Skrip utiliti automasi kemas kini komponen pentadbir (`AdminManagement.jsx` & `AdminAnalyticsLogs.jsx`).
