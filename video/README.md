## 🚀 Cara Menggunakan Studio Video:

### Langkah 1: Buka Studio di Browser
Klik dua kali pada fail `index.html` di dalam folder ini atau layari melalui pautan setempat.

### Langkah 2: Merakam Slaid (Jika Perlu Visual Tambahan)
1. Pilih tab **📺 Slaid Video 16:9**.
2. Tekan butang **⛶ Mod Skrin Penuh** atau kekunci **F11**.
3. Gunakan kekunci **Anak Panah Kanan (▶)** atau tekan **Auto-Play** sambil merakam skrin menggunakan *OBS Studio* atau *Xbox Game Bar (Win + G)*.

### Langkah 3: Merakam Suara / Kamera Ahli
1. Pilih tab **📜 Teleprompter Skrip**.
2. Pilih nama pembicara (contoh: *Adam Darwish*, *Hazim Afiq*, atau *Muhammad Syahmi*).
3. Laraskan kelajuan skrol dan tekan **▶️ Mula Skrol**.
4. Rakam suara menggunakan perakam suara telefon pintar atau mikrofon lavelier.

### Langkah 4: Suntingan Akhir (CapCut PC / Clipchamp)
1. Gabungkan rakaman wajah ahli kumpulan, rakaman demonstrasi skrin website live, dan slaid visual.
2. Tambahkan sari kata automatik (*Auto-Captions*).
3. Masukkan muzik latar santai berirama korporat/teknologi moden (*Corporate Tech Ambient*) pada tahap kekuatan 15-20%.
4. Eksport pada resolusi **1080p Full HD (1920x1080) 60fps / 30fps**.
